# 🌴 BoraNatal

**Descubra Natal, Rio Grande do Norte!**

O BoraNatal é um aplicativo mobile de turismo desenvolvido para ajudar usuários a descobrir praias, pontos turísticos e experiências em Natal-RN. O projeto tem como objetivo facilitar a exploração de destinos locais por meio de uma interface intuitiva e recursos de busca e navegação.

## 📱 Funcionalidades

- 🔎 **Busca de destinos:** encontre atrações pelo nome.
- 🏖️ **Categorias:** explore destinos organizados por tipo.
- ❤️ **Favoritos:** marque os lugares que deseja visitar.
- 🗺️ **Google Maps:** abra a localização ou pesquise como chegar ao destino.
- 🖼️ **Imagens e informações:** visualize os destinos em cartões.
- 📱 **Interface mobile:** navegue por uma experiência pensada para dispositivos móveis.

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js instalado
- npm
- Visual Studio Code
- Expo Go, para testar em um dispositivo compatível

### Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/boranatal.git
```

Entre na pasta:

```bash
cd boranatal
```

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npx expo start
```

Siga as instruções do terminal para executar o aplicativo no dispositivo ou em um emulador compatível.
